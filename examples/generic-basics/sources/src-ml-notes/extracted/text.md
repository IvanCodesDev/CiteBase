# 机器学习实践笔记

## 过拟合与泛化
过拟合表现为训练误差持续下降而验证误差开始上升。
正则化、早停和数据增强是控制过拟合的常用手段。

## 模型评估
k 折交叉验证把数据分成 k 份轮流做验证集，比单次划分的评估方差更小。
时间序列数据做交叉验证必须保持时间顺序，禁止用未来数据训练预测过去。

## 数据泄漏
数据泄漏指训练特征中混入了目标变量的信息，导致线下指标虚高而线上失效。
在划分训练与测试集之前做全量标准化或特征选择是常见的泄漏来源。

## 超参数搜索
网格搜索在低维超参数空间可行，高维时随机搜索通常更高效。

## 时间序列基线
移动平均适合平稳序列的短期平滑预测，窗口越大越平滑但滞后越明显。
小样本单调趋势序列可先尝试简单基线再考虑复杂模型。
