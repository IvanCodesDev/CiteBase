# 竞争格局与创新点分级

> 状态：调研快照 2026-08-20（立项实施前**必须重核**各项目进展）· 基线 2026-08-21
> 写作纪律：诚实竞距——不贬低竞品、不虚构差距；每个设计点标注〔真差异化〕〔组合实践〕〔大路货〕。

## 1. 三条既有路线的结构性缺陷

| 路线 | 代表 | 结构性缺陷 |
|---|---|---|
| A：Agentic RAG / 检索时理解 | 各类 RAG 框架、agentic search | 理解成本 O(查询数 × 语料复杂度) 永不摊销；语料无治理；知识不沉淀 |
| B：AI 编译文档 | llm-wiki、DeepWiki | 产物是散文页面，论断不可逐条验证；无出处门槛；无漂移检测；无执行回流 |
| C：平台型知识库 | RAGFlow、Dify、FastGPT、MaxKB、AnythingLLM | 切块 + 向量 + 引到块，粒度不到论断；基础设施重；面向问答不面向 Agent 长程任务 |

## 2. 出处优先新兴赛道（2026-08 核实的五个早期项目）

| 项目 | 核心贡献 | 与 CardVault 的关系 |
|---|---|---|
| Accreta | Agent 编译维护的互链 wiki；行级出处 + 源修订漂移检测；矛盾页 | 理念重合度最高；无论断结构、无执行回流、无时效模型 |
| AuditRAG | 句级引用映射；忠实度二次核验；证据报告导出 | 只管「答案可验」不管「知识沉淀」；无编译层 |
| AttestDB | 「带源 claim」为原子单元；源失效级联标记；防篡改哈希链 | claim-only 无人可读层；DB 形态失去 git 工作流 |
| NuggetIndex (SIGIR 2026) | 事实效期区间；争议标记；时间感知检索 sidecar | 时效模型值得吸收；是检索旁挂不是知识基座 |
| LLM-Ledger | claim + valid_from/until + as-of 查询；CI 校验账本完整性 | 「CI 即治理」思路一致；无卡片层、无回流 |

**判断**：五个项目全部早期（个位数到两位数 star），赛道没有赢家；「论断级出处 + 漂移审计」已从空白变成**并行竞争**。入场差异必须落在它们都没有的位置。

## 4. 创新点诚实分级

### 〔真差异化〕当前全场无人做

1. **执行证据回流闭环 + 知识贡献度度量**——唯一把「知识库有没有用」变成可测量问题的设计（[ADR-0007](../adr/0007-execution-evidence-backflow.md)）；
2. **卡片 / 论断双粒度合一**——人可读与机器可验不再二选一（[ADR-0002](../adr/0002-dual-granularity-card-claim.md)）；
3. **Vault 联邦：知识即依赖**——deps/lock/命名空间/跨库出处验证（M5 设计，[存储与版本化 §5](../architecture/storage-and-versioning.md)）；
4. **编译期 + 消费期 + 回流期三段注入防御**（[威胁模型](../security/threat-model.md)）。

### 〔组合实践〕他人已有，我们组合并做严

AI 编译循环（llm-wiki / Accreta）· span 级出处（Accreta / AuditRAG）· 漂移检测（Accreta）· 时效与 as-of（NuggetIndex / LLM-Ledger）· CI 即治理（LLM-Ledger）· 检索漏斗与渐进披露（编码 Agent 生态实证路线）· 矛盾不消解（Accreta / NuggetIndex）· 可复现编译回放（构建系统思想移植）· 失效信号总线（三通道统一为一套状态机）。

### 〔大路货〕不作为卖点宣传

BM25 检索 · MCP 封装 · 静态站点导出 · YAML frontmatter 卡片格式。

## 5. 入场判断

1. **窗口存在但在收窄**：出处优先已成新兴共识，M2 尽早公开占位；
2. **护城河排序**：回流 + 贡献度（数据壁垒）> 双粒度模型（迁移成本）> 联邦（网络效应，最晚兑现）；
3. **对 Accreta 的姿态**：理念盟友、实现竞品；兼容其「团队工程知识活文档」场景，用论断结构与回流做增量；
4. **放弃条件**（对应 R3）：若竞品完整实现回流 + 贡献度 + 双粒度，转向做其最佳垂直实现（数学建模场景），不硬碰通用市场。
